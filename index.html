Privacy Policy & Data Safety

Google Play Developer Policy compliant. Last updated August 2026.

ZipToApk is built with a strict zero‑telemetry, offline‑first architecture. Your source code and personal tokens never touch any intermediary server — they go straight from your device to GitHub's and Google's official APIs.

1. Information We Collect

  • User credentials — your GitHub Personal Access Token and Gemini API key are stored strictly on‑device, protected by hardware‑backed Android Keystore encryption (AES‑256‑GCM).
  • Project source files — extracted ZIP contents stay in your device's isolated app storage and are sent only to GitHub's official REST API (api.github.com).
  • We do not collect, sell, or transmit personally identifiable information, browsing history, or analytics to any private server.

2. How We Use Data

  • Facilitating direct Git blob, tree, and commit pushes to your authorized GitHub repositories.
  • Processing AI code‑transformation requests via Google's official Gemini API.
  • Inspecting local project files for dependencies (e.g. Firebase, Room) to flag missing configuration.

3. Third‑Party Services & APIs

  • GitHub API (api.github.com) — authenticating and pushing code commits.
  • Google Gemini API (generativelanguage.googleapis.com) — optional AI code assistance.
  • Google Play Services — optional standard crash reporting and app distribution.

4. Permissions Requested

  • INTERNET / ACCESS_NETWORK_STATE — required to reach GitHub and Gemini APIs, and to pause an upload gracefully if you go offline.
  • REQUEST_INSTALL_PACKAGES — lets a build artifact you downloaded be installed without leaving the app.
  • POST_NOTIFICATIONS — a single notification when a push or build finishes.
  • READ_EXTERNAL_STORAGE (scoped) — only to read a .zip you explicitly selected via the system file picker.

5. Data Retention & Deletion

  • Clear all cached files, tokens, and profile data anytime via Disconnect / Clear Credentials in Settings.
  • Uninstalling the app immediately deletes all local encrypted credentials and cached files from your device.

6. Children's Privacy

  • ZipToApk is a developer utility not directed at children and does not knowingly collect data from children under 13.

How this works

1. Connect: OAuth Device Flow with repo,workflow or PAT fallback.

2. Repository: browse/create the repo and choose the branch; public visibility gets an explicit confirmation.

3. ZIP: extract and inspect the project. Attach/paste google-services.json and signing/keystore data when required.

4. Security: possible secrets are shown before push; you can cancel, exclude flagged files, or explicitly bypass.

5. Push: blobs → tree → commit → branch ref, after a confirmation dialog.

6. Actions: monitor the workflow and artifact state. Failed builds expose Fix with AI.

7. AI: Fix Bugs, Add Feature, Refactor, Explain Code. Review before applying changes.

8. APK: download/QR controls appear only when a successful artifact is available. Native package installation is Android-only.
