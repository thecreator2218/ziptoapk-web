Privacy Policy

How ZipToApk handles information when you use the Android application.

Last updated: August 31, 2026
Short version: ZipToApk is a developer utility. The app is designed to process project files locally and communicate directly with services you choose to use, such as GitHub and Google Gemini. We do not operate an advertising or analytics profile of your project source code.

1. Information We Handle

Depending on the features you use, ZipToApk may handle:

  • GitHub account information needed to authenticate you and access the repositories you authorize.
  • GitHub access credentials/tokens used to perform authorized repository operations.
  • Project ZIP files and extracted project files that you explicitly select for processing.
  • Optional Google Gemini API credentials when you choose to use the AI code-assistance features.
  • Optional project configuration and signing material, such as google-services.json or a keystore/base64 signing value, when you explicitly provide them.
  • Build and repository information needed to monitor GitHub Actions and retrieve build artifacts.

2. How We Use Information

  • To authenticate your GitHub account and connect to repositories you authorize.
  • To inspect a project ZIP and identify project structure, dependencies, configuration requirements, and possible exposed credentials.
  • To push project files to the GitHub repository and branch selected by you.
  • To monitor GitHub Actions builds and provide build status and available APK artifacts.
  • To process optional AI coding requests when you explicitly enable and use the Gemini assistant.
  • To apply optional configuration/signing files that you explicitly provide for your build workflow.

3. GitHub

GitHub is required for the repository and cloud-build workflow. When you connect GitHub, ZipToApk requests the permissions required for the features you choose and uses GitHub's APIs to authenticate, read repository information, create/update repository content, and monitor Actions runs.

Your use of GitHub is also governed by GitHub's Privacy Statement and GitHub's own terms and policies.

4. Google Gemini

Gemini assistance is optional. If you enable it and submit a coding request, relevant project context may be sent to Google's Gemini API so that the requested analysis or code transformation can be performed.

Google's handling of information is governed by Google's Privacy Policy and the terms applicable to the Gemini/API service you use.

5. Project Source Code & Sensitive Information

ZipToApk includes a security-oriented scan before a project is pushed. The scanner looks for patterns that may indicate items such as API keys, access tokens, private keys, passwords, or other credentials.

A warning from the scanner is not a guarantee that every secret has been detected. You remain responsible for reviewing your project before making a repository public.

Never intentionally place a production password, private key, recovery code, or other highly sensitive credential in a public repository.

6. Local Storage, Retention & Deletion

The Android application is designed to keep working data and credentials in the application's local storage rather than sending them to a ZipToApk-owned intermediary server.

  • You can disconnect your GitHub account and clear stored credentials from the app's settings.
  • Cached project data can be removed through the app's available clear/delete controls.
  • Uninstalling the Android application removes its app-private local data according to Android's normal application-data lifecycle.
  • Information already committed to GitHub or processed by third-party services is not deleted merely by uninstalling ZipToApk; you must manage that information through the relevant service.

7. Data Sharing

ZipToApk does not sell your personal information or project source code. Information is shared with third-party services only when required for a feature you choose to use, including GitHub repository/build operations and optional Google Gemini requests.

8. Children's Privacy

ZipToApk is a developer-focused utility and is not directed toward children. We do not knowingly design the service to collect personal information from children.

9. Security

We use reasonable technical measures appropriate to the Android application and its workflow to protect locally stored credentials and data. No method of electronic storage or transmission is completely secure, so users should also follow good credential-security practices and avoid committing secrets to public repositories.

10. Changes to This Policy

This policy may be updated when the app's features, integrations, or data practices change. The latest version will be published on this page with an updated date.
