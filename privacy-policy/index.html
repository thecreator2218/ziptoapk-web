Privacy Policy

How ZipToApk handles information when you use the application.

Last updated: September 1, 2026
Short version: ZipToApk is a developer utility that lets you select project ZIP files, inspect them, check for potentially exposed credentials, use optional AI assistance, and work with GitHub for repository and build operations.

1. Information We Handle

Depending on the features you use, ZipToApk may handle:

  • GitHub account and repository information needed for the GitHub features you choose to use.
  • Project files from ZIP files that you explicitly select for processing.
  • Optional AI-assistance information that you choose to submit to the Gemini service.
  • Optional project configuration files that you explicitly provide for a project build.
  • Build and artifact information needed to show build status and provide available build artifacts.

2. How We Use Information

  • To process and inspect the project ZIP file you select.
  • To check selected project files for patterns that may indicate exposed credentials or sensitive information before a GitHub push.
  • To perform GitHub repository and build operations that you request.
  • To show build status and provide available build artifacts.
  • To provide optional AI-assisted code analysis or troubleshooting when you choose to use that feature.

3. GitHub

When you use GitHub features, ZipToApk communicates with GitHub to perform the repository and build operations you request. Information handled by GitHub is subject to GitHub's own privacy practices.

GitHub Privacy Statement

4. Google Gemini

AI assistance is optional. If you choose to use it, information necessary for the requested AI operation may be sent to Google's Gemini service. Google's handling of that information is governed by Google's applicable privacy practices.

Google Privacy Policy

5. Advertising

ZipToApk may display advertisements through Google AdMob.

6. Project Source Code & Sensitive Information

ZipToApk performs a security-oriented check on selected project files before a GitHub push. The check looks for common patterns associated with API keys, access tokens, passwords, private keys, and similar credentials.

The scanner cannot guarantee that every secret will be detected. You remain responsible for reviewing your project and deciding what is safe to publish.

7. Storage, Retention & Deletion

ZipToApk is designed to process working project data on the user's device and to communicate with the third-party services required for the features the user chooses to use.

ZipToApk does not operate an intermediary service for selling or maintaining copies of users' project source code.

Information that you send to GitHub, Google, or another third-party service is handled according to that service's policies and cannot necessarily be removed by uninstalling ZipToApk.

8. Data Sharing

ZipToApk does not sell personal information or project source code. Information may be provided to third-party services when necessary for a feature you explicitly use, including GitHub repository and build operations, optional Gemini AI assistance, and advertising.

9. Children's Privacy

ZipToApk is a developer-focused application and is not directed toward children. We do not knowingly collect personal information from children.

10. Security

Reasonable measures are used within the application to protect information handled by the app. However, no electronic storage or transmission method is completely secure.

Users should avoid publishing passwords, private keys, API keys, or other sensitive credentials in public repositories.

11. Changes to This Policy

This Privacy Policy may be updated when the application's features or data practices change. The latest version will be published on this page with an updated date.
