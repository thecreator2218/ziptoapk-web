ZipToApk Privacy Policy

This Privacy Policy explains how ZipToApk handles information when you use its GitHub, AI assistance, build, download, and advertising features.

Last Updated: September 3, 2026
Your data, your actions

ZipToApk processes project files primarily on your device and sends information to third-party services only when required for features you choose to use. GitHub, Cloudflare, Google Gemini, and Google Mobile Ads may process information as described below.

1. Information We Handle

GitHub Credentials

GitHub Personal Access Tokens (PATs), GitHub OAuth access tokens, and user-provided Gemini API keys may be stored locally on the Android device using protected storage with Android Keystore AES-256-GCM encryption.

Project Files

Project ZIP archives and extracted project/source files are processed locally by ZipToApk. When you choose to push or update a project, selected files are transmitted to GitHub through GitHub's official APIs.

GitHub Account and Repository Information

ZipToApk accesses the GitHub account and repository information required for the GitHub features you choose to use. This may include information needed for repositories, files, branches, commits, GitHub Actions, build status, and build artifacts.

GitHub OAuth

During GitHub OAuth sign-in, authorization information and the one-time authorization code may pass through the application's Cloudflare Worker. This allows the GitHub OAuth Client Secret to remain off the Android device.

The Cloudflare Worker is used as an OAuth broker and token-exchange service. It is not used as general project-source-code storage.

Third-Party Services

GitHub, Cloudflare, Google Gemini, and Google Mobile Ads may process information required to provide features that you choose to use.

2. How We Use and Process Information

ZipToApk uses information to provide the application functionality requested by the user.

  • Create and update GitHub repositories, files, branches, and commits.
  • Read GitHub Actions and build status information.
  • Access GitHub Actions build artifacts when requested.
  • Process selected code or context with Google Gemini when the user invokes the AI assistant.
  • Maintain a limited recent project history/checkpoint list locally on the device.

ZipToApk does not automatically send all project files to Google Gemini. Only the code or context selected or required for an AI request is processed for that request.

3. Project and APK Downloads

ZipToApk may download project archives or GitHub Actions build artifacts from repositories authorized by the user.

When an APK build artifact is downloaded, the application processes and extracts it locally and presents an explicit installation action to the user.

ZipToApk does not silently install APK files and does not use this functionality to silently self-update the ZipToApk application.

4. Local Project History

ZipToApk may keep a limited recent project history or checkpoint list locally on the device to display recent project activity.

This history contains feature-related metadata and is not a developer-hosted backup of project source code.

5. Advertising

ZipToApk may display advertisements using Google Mobile Ads (AdMob).

When the Google Mobile Ads SDK is used, Google may automatically process information such as IP address, advertising or device identifiers where applicable, app or user interactions such as app launches and ad interactions, and diagnostic or performance information.

Such information may be processed for advertising, analytics, fraud prevention, and SDK operation according to Google's applicable policies and user or device settings.

Advertising availability is controlled by the application's configured advertising settings.

6. Third-Party Services

GitHub

GitHub is used for authorized account, repository, file, branch, commit, GitHub Actions, and build-artifact functionality.

Cloudflare

The application's Cloudflare Worker is used for GitHub OAuth authorization and server-side token exchange. It is not used as general project-source-code storage.

Google Gemini

Google Gemini may receive selected code or context when the user invokes AI assistance.

Google Mobile Ads (AdMob)

Google Mobile Ads provides advertising and may process advertising-related device and interaction information.

7. Storage, Retention and Deletion

  • Logout or Disconnect removes locally stored credentials and app-managed account or configuration data according to the application's implemented behavior.
  • Clearing Gemini configuration removes the locally stored Gemini API key.
  • Uninstalling the application removes its local application data subject to Android storage and backup behavior.
  • A limited recent project history or checkpoint list may be stored locally on the device.
  • Information already transmitted to GitHub, Google, Cloudflare, or another third-party provider is subject to that provider's own retention and deletion policies.

8. Security

Sensitive credentials stored locally by ZipToApk are protected using Android Keystore AES-256-GCM encryption.

Supported network communication uses HTTPS and the secure API mechanisms provided by the relevant services where applicable.

The GitHub OAuth Client Secret is kept server-side in the Cloudflare Worker rather than embedded in the Android application.

9. Children

ZipToApk is a developer-focused application and is not specifically directed to children.
