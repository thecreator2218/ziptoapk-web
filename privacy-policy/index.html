Privacy Policy

How ZipToApk handles information when you use the application.

Last updated: September 3, 2026
Short version: ZipToApk is a developer utility for working with selected project files, GitHub repositories and builds, optional Gemini AI assistance, and related developer tools. Project processing is primarily performed on your device, while information is sent to third-party services only as needed for features you choose to use.

1. Information We Handle

Depending on the features you choose to use, ZipToApk may access, process, or store:

  • GitHub account and authorization information required to connect your GitHub account and use authorized repository and workflow features.
  • Project files contained in ZIP archives or other project files that you explicitly select for processing.
  • Credentials and configuration such as GitHub access tokens or a Gemini API key when required by features you configure. App-managed credentials are stored locally using protected Android storage where supported.
  • Optional AI-assistance information such as selected code or relevant project context when you explicitly use the Gemini-powered AI assistance feature.
  • Repository, workflow, build and artifact information required to perform requested GitHub operations, display build status, and retrieve available build artifacts.
  • Advertising-related information that may be processed by the Google Mobile Ads SDK when advertising is enabled, as described below.

2. How We Use Information

Information is handled only as needed to provide the features you request, including:

  • Processing and inspecting project files that you select.
  • Checking selected project files for patterns that may indicate exposed credentials or sensitive information.
  • Creating or updating repositories, files, commits, and supported GitHub Actions workflows when requested by you.
  • Reading build or workflow status and retrieving build artifacts when you request those features.
  • Providing optional AI-assisted code analysis or troubleshooting when you choose to use that feature.
  • Providing advertising where the application's advertising feature is enabled.

3. GitHub & Authentication

When you connect GitHub, ZipToApk uses GitHub's authorization services and APIs to perform the GitHub features you request within the permissions you authorize.

During GitHub OAuth sign-in, limited authorization information is processed through a Cloudflare Worker used for the OAuth flow and server-side token exchange. The GitHub OAuth Client Secret is kept server-side and is not embedded in the Android application.

Repository files are sent to GitHub only when you choose an operation that requires them, such as pushing or updating project content. Information received and retained by GitHub is subject to GitHub's own policies.

GitHub Privacy Statement

4. Google Gemini

Gemini AI assistance is optional. When you choose to use this feature, selected code, prompts, or relevant project context required for your request may be sent to Google's Gemini service.

ZipToApk does not send your entire project to Gemini merely because a project is opened. Information is sent when required for an AI request that you initiate.

Information processed by Google's services is subject to Google's applicable terms and privacy practices.

Google Privacy Policy

5. Advertising

ZipToApk may display advertisements using Google Mobile Ads (AdMob) when advertising is enabled in the application.

The Google Mobile Ads SDK may automatically process information such as IP address, app interactions, diagnostic information, and device or advertising identifiers for purposes such as advertising, analytics, and fraud prevention. The exact information processed can depend on the SDK version, device settings, consent settings, and advertising configuration.

Advertising-related information processed by Google is governed by Google's applicable privacy practices.

Google Privacy Policy

6. Project Files & Sensitive Information

Project ZIP archives and extracted source files selected in ZipToApk are primarily processed on the user's device.

Before certain GitHub operations, ZipToApk may perform a security-oriented check for common patterns associated with API keys, access tokens, passwords, private keys, and similar credentials.

This check is intended to help identify possible accidental exposure but cannot guarantee that every secret or sensitive value will be detected. You remain responsible for reviewing project content before publishing or sending it to a third-party service.

7. Third-Party Services

ZipToApk uses third-party services only where required for the corresponding features you choose to use. These may include:

  • GitHub — for account authorization, repositories, files, commits, workflows, build information, and artifacts.
  • Cloudflare — for limited server-side processing required by the GitHub OAuth authorization flow.
  • Google Gemini — for optional AI-assisted requests initiated by you.
  • Google Mobile Ads (AdMob) — for advertising and related advertising, analytics, and fraud-prevention processing when advertising is enabled.

Information sent to a third-party provider is also governed by that provider's applicable terms, privacy policy, and retention practices.

8. Storage, Retention & Deletion

Working project files are primarily processed locally on the device. App-managed credentials and configuration required for enabled features may also be stored locally using Android's available protected storage mechanisms.

Disconnecting or logging out of a connected service removes applicable app-managed credentials and related local connection information from the device. Removing a locally configured Gemini API key removes that key from the application's local configuration.

Uninstalling ZipToApk removes app-managed local data subject to Android's storage and backup behavior.

Data already transmitted to GitHub, Google, Cloudflare, or another third-party service is subject to that provider's own retention and deletion practices and is not necessarily removed when ZipToApk is uninstalled or disconnected.

9. Data Sharing

ZipToApk does not sell users' personal information or project source code.

Information is shared with third-party services only as necessary for features that you use, such as GitHub repository and build operations, GitHub OAuth processing through Cloudflare, optional Gemini AI assistance, and Google Mobile Ads.

10. Children's Privacy

ZipToApk is a developer-focused utility and is not designed or directed specifically toward children.

If you believe that information relating to a child has been provided to us inappropriately, you may contact us using the information below.

11. Security

ZipToApk uses reasonable technical measures intended to protect app-managed information. Sensitive credentials stored by the application are kept in protected local storage where supported, and the GitHub OAuth Client Secret is maintained server-side rather than being included in the Android application.

Communications with supported online services use their secure HTTPS endpoints. However, no method of electronic storage or transmission can be guaranteed to be completely secure.

Users should review project files carefully and avoid publishing passwords, private keys, API keys, access tokens, or other sensitive credentials in repositories.

12. Your Choices

You control whether to select project files, connect GitHub, configure Gemini AI assistance, or initiate operations that send project information to supported third-party services.

You may disconnect supported connected services, remove locally stored configuration where the application provides that option, or uninstall the application to remove app-managed local data subject to Android's storage and backup behavior.

13. Changes to This Policy

This Privacy Policy may be updated when ZipToApk's features, service providers, or data practices change. The latest version will be published on this page with the updated date shown above.
